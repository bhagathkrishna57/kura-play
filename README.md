## 🎮 Vision & Manifesto

KURA is a bespoke, high-octane cyber arcade built to eliminate boredom instantly. 

Designed and engineered from the ground up by **Bhagath Krishna.M**, KURA rejects bloated game engines, heavy frameworks, and tedious tutorials in favor of pure, responsive kinetic flow:
- **0.1ms Input Latency:** Direct Canvas 2D hardware-accelerated rendering.
- **Pure Handcrafted Code:** 100% vanilla JavaScript, HTML5, and CSS3. Runs instantly offline or from any browser with zero build steps or dependencies.
- **Zero-Boredom Protocol:** Instant game launches, rapid switching via hotkeys, and intense reflex challenges.

## ⌨️ Tactical Controls & Hotkeys

- **`[R]`** — **Try Again / Restart:** Instantly restart the current game round at any time.
- **`[N]`** — **Jump Sector:** Instantly skip to the next game at any time without leaving the session.
- **`[SPACE]` / `[ENTER]`** — **Action & Try Again:** Jump, slice, fire reflex cue, or retry a round instantly.
- **`[ESC]` / `[BACKSPACE]`** — **Return to Hub:** Seamlessly exit back to the sector grid.
- **`MODE: SOLO / 2-PLAYER`** — Local 2-Player head-to-head on the same keyboard.
- **`PARTY LOBBY`** — PeerJS WebRTC multiplayer room lobbies to share room codes with friends.

## 🚀 How to Run Locally

No Node.js, npm, or local servers required!

1. Clone or download this repository:
   ```bash
   git clone https://github.com/bhagathkrishna57/kura-play.git
   ```
2. Double-click `index.html` or `launch.bat` to launch immediately in Google Chrome or any modern browser.
